# Galtype 1.0.0

Meltype を元にした、ギャル文字入力の最初のリリースです。

- 日本語と英語の自動判定に、Galjp 5.0.0 のギャル文字変換を追加しました。
- 入力中の文字、変換候補、確定した文字に、同じギャル文字設定を使います。
- 英字、数字、かな、漢字、記号の変換と、URL などの保護を設定できます。
- Node.js と Galjp を配布物に同梱し、利用者側で Node.js を追加する手間をなくしました。
- 実行ファイル、保存先、入力方式登録、更新先を Meltype と分けました。

初回起動時はギャル文字変換が ON です。Windows では設定画面から変更でき、macOS と Linux では Galtype の設定ファイルで変更できます。

macOS と Linux はプレビュー版です。署名や公証の有無は配布時の設定によります。詳しい確認手順と公開条件は [リリース手順](../RELEASE.md) を参照してください。

Meltype 由来部分の著作権と GPL-3.0-or-later の条件を引き継ぎます。Galtype 固有の不具合は [Galtype の Issue](https://github.com/oto-lab/Galtype/issues) に報告してください。
