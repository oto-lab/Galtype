# Galtype 0.1.0

Meltype を元にした、Windows 用のギャル文字入力の最初のリリースです。

- 日本語と英語の自動判定に、Galjp 5.0.0 のギャル文字変換を追加しました。
- 入力中の文字、変換候補、確定した文字に、同じギャル文字設定を使います。
- 英字、数字、かな、漢字、記号の変換と、URL などの保護を設定できます。
- Node.js と Galjp を配布物に同梱し、Node.js を別途インストールせずに使えます。
- 実行ファイル、保存先、IME 登録、起動時の登録、更新先を本家 Meltype と分けました。

初回起動時はギャル文字変換が ON です。設定画面から OFF にすると、通常の日本語入力に戻せます。

配布対象は Windows のみです。macOS / Linux のコードは将来の対応候補として残していますが、この版では動作確認や配布を行いません。
